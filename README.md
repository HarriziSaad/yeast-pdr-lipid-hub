# yeast-pdr-lipid-hub

Code and result tables for "A pre-registered, structure-resolved analysis of fungal multidrug transporters across 1,154 yeast genomes".

| Folder | Contents |
|---|---|
| `orthology` | retrieval of full-size PDR pumps, alignments, gene trees, gate G1 |
| `conservation` | hub conservation test (H6) |
| `structure` | structure and model mapping, pocket benchmark |
| `validation` | curated mutant table, exploratory analyses (M1, M2, B1, B2), natural variation (H5), fluconazole resistance (E1) |
| `registration` | frozen site classes, scripts, SHA-256 of the registered documents |

Input data are public; sources are listed in the Data Availability Statement of the paper.
